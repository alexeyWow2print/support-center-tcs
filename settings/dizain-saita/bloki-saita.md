В админ-панели сайта можно сверстать вручную такие блоки сайта как шапка и футер.



## Общие положения

Шапка и футер отображаются на всех страницах сайта и имеют стандартный вид. В админ-панели имеется возможность изменить стандартный вид шапки и футера с помощью верстки html-кода.

![](<../../.gitbook/assets/image (1056).png>)



Статус (ползунок) напротив каждого блока отвечает за вариант отображения.

-  **Включен**\
   Применяется индивидуальная верстка, код которой располагается внутри данного блока.

-  **Выключен**\
   Применяется стандартный (по умолчанию) вид блока.





### Редактор блока

При нажатии на один из блоков, откроется страница с инструментом редактирования.

![](<../../.gitbook/assets/image (870).png>)



В левой части располагается:

-  **Режим тестирования**\
   При активации данного режима, индивидуальную верстку на сайте будут видеть только авторизованные пользователи. Обычные клиенты сайта будут видеть стандартную верстку.\
   Если вы только начинаете вносить изменения в данный блок, то воспользуйтесь режимом тестирования.

:::note 

Режим тестирования работает только при статусе блока «Выключен».

:::



-  **html**\
   Текстовый редактор, в который необходимо располагать индивидуальную верстку.



В правой части располагаются теги, которые можно использовать в коде верстки блока:

-  **\{LogoUrl}**\
   Логотип сайта.

-  **\{LogoAlt}**\
   Alt для логотипа -- берется из настроек логотипа.

-  **\{CityLocationWidget}**\
   Виджет для выбора города.

-  **\{CabinetProfileName}**\
   Имя авторизованного клиента.

-  **\{CabinetProfileUrl}**\
   Ссылка на профиль.

-  **\{CabinetOrdersUrl}**\
   Ссылка на заказы.

-  **\{CabinetExitUrl}**\
   Ссылка на выход.

-  **\{CartUrl}**\
   Ссылка на корзину.

-  **\{CompanyName}**\
   Название компании -- берется из [контактных данных](./../drugie-nastroiki/kontaktnye-dannye) из поля «Наименование, отображаемое на сайте».

-  **\{CompanyPhone}**\
   Телефон компании -- берется из [контактных данных](./../drugie-nastroiki/kontaktnye-dannye) из поля «Контактный телефон типографии».

-  **\{CompanyAddress}**\
   Адрес компании -- берется из [контактных данных](./../drugie-nastroiki/kontaktnye-dannye) из поля «Адрес типографии».

-  **\{CompanyEmail}**\
   Email компании -- берется из [контактных данных](./../drugie-nastroiki/kontaktnye-dannye) из поля «Email типографии».

-  **\{WidgetMenu1}**\
   Меню «Верхнее меню».

-  **\{WidgetMenu2}**\
   Меню «Меню в футере (левая колонка)».

-  **\{WidgetMenu3}**\
   Меню «Меню в футере (правая колонка)».
