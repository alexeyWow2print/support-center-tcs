---

В данном разделе вы узнаете как:

-  заполнить контактные данные для отображения на сайте;

-  настроить почтовый сервис для отправки уведомлений с сайта;

-  создать свои шаблоны писем для уведомлений с сайта;

-  настроить производственный календарь;

-  внести свои шаблоны сроков производства;

-  назначить правила сборных тиражей;

-  настроить автоматическую отправку файлов с сайта на свой FTP-сервер;

-  редактировать данные в блоке Информация в Основных модулях Калькуляции товара;

-  работать с макетом (назначение шаблона названия, настройки дизайна и загрузки и т.д.);

-  Разместить в корне сайта какой-либо код;

-  Настроить порядок оформление заказа;

-  Настроить сайт для разных языков;

-  Создать/изменить форму обратной связи;

-  Добавить возможность авторизовываться на сайте через соцсети.
