Как настроить интеграцию с транспортной компанией CDEK?



## Видеоинструкция

[Ссылка на VK Видео](https://vkvideo.ru/video-150544481_456239080)

[video:https://www.youtube.com/watch?t=50s&v=-Y2OUuCA6Co]



## Для того, чтобы настроить данную интеграцию, вам необходимо:



**1)** заключить договор как *интернет-магазин* с транспортной компанией "СДЭК" (во время заполнения анкеты на сайте <https://cdek.ru/>, проставьте галочку на данный пункт).



**2)** после заключения договора, запросите ключи для интеграции, которые вам вышлют в обратном письме (подробнее <https://cdek.ru/integration> -> вкладка "Часто задаваемые вопросы" ->  вопрос "Где я могу найти тестовые и боевые ключи?")



**3)** полученные ключи необходимо внести в Настройки -> Интеграции -> Доставка -> CDEK.

В случае, если требуется добавить интеграцию, нажмите на ![](./cdek.png){width=40px height=40px} -> Добавить новую интеграцию  -> выберите из списка CDEK -> кнопка "Подключить"

![](<../../../.gitbook/assets/image (2411).png>)



-  Заполните поле *Название\** и введите полученные ключи:

![](<../../../.gitbook/assets/image (3268).png>)



-  Выберите свой город отправки и укажите в поле *Код ПВЗ для привоза* код вашего пункта приема. Посмотреть код можно на сайте CDEK, в разделе Пункты CDEK <https://www.cdek.ru/ru/offices>

-  Включите тарифы, которые будут доступны для клиентов на сайте (там же, в настройках интеграции):

как правило, тарифы для интернет-магазинов -- "Посылка склад-склад" и "Посылка склад-дверь", остальное по желанию (или по договору с транспортной компанией).

![](<../../../.gitbook/assets/image (993).png>)



При включении тарифов появится окно с настройками допустимого веса.

![](<../../../.gitbook/assets/image (3390).png>)

\
Вес "от" желательно выставить "0", чтобы клиент мог оформить доставку продукта весом даже 1 грамм.\
Вес "до" может быть ограничен самой транспортной компанией (в зависимости от тарифа), значения 30-50 кг будут оптимальными.

После включения тарифов доставки, сохраните настройки самой интеграции.

\
**4)** активируйте выбранные в интеграции способы доставки на сайте. Для этого в Настройки -> Доставка -> Доставка на сайте -> отсортируйте по Типу "CDEK" и включите те способы доставки, которые выбрали ранее в настройках интеграции.
